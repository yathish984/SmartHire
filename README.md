# SmartHire – Full Stack Job Recruitment & Applicant Tracking Platform

SmartHire is a full-stack job recruitment and Applicant Tracking System (ATS) designed to connect candidates and recruiters through a simple and efficient recruitment platform.

## 🚀 Features

### Candidate
- Candidate registration and login
- Candidate profile management
- Browse available jobs
- Apply for jobs
- Track application status

### Recruiter
- Recruiter registration and login
- Create and manage job postings
- View candidate applications
- Manage recruitment process

### Admin
- Manage users
- Manage recruiters and candidates
- Manage job postings
- Monitor platform activity

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- MongoDB
- Mongoose

### Tools
- Git & GitHub
- Postman
